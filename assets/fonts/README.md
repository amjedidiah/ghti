# Fonts for generated images and PDFs

Static font files for `next/og` (`app/opengraph-image.tsx`) and `@react-pdf/renderer` (`components/pdf/`), which need TTF, OTF or WOFF files (not WOFF2 or variable fonts). The site itself loads its fonts with `next/font/google`.

| File                                     | Font                  | Source                               |
| ---------------------------------------- | --------------------- | ------------------------------------ |
| `playfair-display-latin-700-normal.woff` | Playfair Display Bold | `@fontsource/playfair-display@5.3.0` |
| `inter-latin-400-normal.woff`            | Inter Regular         | `@fontsource/inter@5.3.0`            |
| `inter-latin-500-normal.woff`            | Inter Medium          | `@fontsource/inter@5.3.0`            |
| `inter-latin-600-normal.woff`            | Inter Semi Bold       | `@fontsource/inter@5.3.0`            |

Both families are licensed under the SIL Open Font License 1.1.
